Portfolio Editor

編輯每支影片的專案資訊

這裡填的內容會在網站上點開影片時，顯示在影片右邊（手機上在影片下方）。

  1. 按下「選擇專案資料夾」，選 Website 這個資料夾（裡面有 index.html 的那個）。
  2. Chrome 會問你是否允許編輯，選「允許」。
  3. 點任何一支影片開始填寫，完成後按「儲存」。
  4. 儲存後，把畫面上的 git 指令貼到 Terminal（或請 Claude 幫你 push），網站幾分鐘後就會更新。
